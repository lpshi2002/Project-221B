모든 자료를 받아 용의자를 좁히는 구조

13장 계획이 끝까지 구현됐을 때의 모습이다. 계산과 검증은 코드가, 추론은 에이전트가, 확정은 사람이 맡는다. 아직 구현되지 않은 설계다.

01 · 전체 아키텍처

자료에서 수사 보드까지

어떤 형식의 자료든 어댑터가 출처 위치를 붙여 저장소에 넣는다. 추론 코어의 결론은 근거 게이트가 원본과 대조해 통과시켜야 보드에 오른다. 수사관은 모델이 만든 증거와 개체 연결을 확인하고, 다음 수사로 모은 자료를 다시 넣는다.

02 · 수사 방법

한 번의 추리가 도는 순서

가설은 모든 용의자와 "아직 드러나지 않은 제3자"에 대해 세운다. 확률은 모델이 말하지 않고, 증거별 가능도 비를 코드가 합산한다. 독립 반론이 유력 가설을 무너뜨리면 가설 단계로 돌아가고(최대 2회), 끝내 결판이 안 나면 지목하지 않고 무엇을 더 확인할지 제안한다.

03 · 평가·개선 루프

실제 사건 없이 베이스를 키우는 방법

정답을 먼저 정하고 흔적을 만드는 합성 사건으로 돌린다. 증거 단위의 정답이 있어서 근거 정확도, 증거 부족 판단력, 모듈 기여도를 채점할 수 있다. 실패 분석으로 만든 규칙은 그 규칙을 만든 문제가 아니라 새 홀드아웃에서만 효과를 잰다.

Code · b221 CLI

코드가 하는 일

  • 형식별 어댑터: 문서·표·이미지·영상·음성 → 증거 + 출처 위치
  • 분석 엔진: 타임라인 병합, 이동 가능성, 알리바이 공백, 충돌 탐지
  • 가능도 합산과 순위, 근거 게이트, 채점
  • 같은 입력이면 같은 결과 — 재현 가능한 근거

Agents · skills

에이전트가 하는 일

  • 정리: 주장과 기록 구분, 남의 말 옮김 구분
  • 전문 소견: 범위와 한계, 참고 카드 인용
  • 가설과 증거별 가능도 비 제시
  • 독립 반론, 다음 수사 제안

Human

사람이 하는 일

  • 개체 연결과 모델이 만든 증거 확인
  • 용의자 목록 확정
  • 최종 지목 승인
  • 다음 수사로 새 자료 수집
