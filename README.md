# 🕵️ 221B — 추리 탐정 AI 하네스

사건 기록을 증거 모델로 정리하고, 모순을 찾고, 경쟁 가설을 세워 반증한 뒤, **원문 인용으로 추적되는 결론**을 내는 추리 하네스입니다.
Claude Code와 Codex에서 스킬로 불러 씁니다. 추리는 에이전트가 하고, 파이썬 CLI는 사건 준비·검증·채점만 합니다.

비전과 로드맵: [prototype-221B.md](prototype-221B.md) · 티저: [teaser-221B.html](teaser-221B.html)

## 쓰는 법

```bash
uv sync
uv run b221 fetch        # True Detective 퍼즐 191개 → data/ (학술 연구용, 커밋 안 함)
```

**Claude Code** 또는 **Codex**를 이 폴더에서 열고:

| 하고 싶은 것 | 이렇게 말하기 |
|---|---|
| 벤치마크 | "221B 평가 10문제로 baseline이랑 full 비교해줘" → `221b-eval` |
| 사건 하나 추리 | "runs/…/td-010 사건 풀어줘" 또는 이야기를 붙여 넣고 "범인 추리해줘" → `221b-investigate` |

Codex에서는 `$221b-eval`, `$221b-investigate`로 직접 부를 수도 있습니다.

## 추리 절차

```
① 정리      인물·증거·사건 → case_model.json (증거마다 원문 인용, "말해주는 것 / 말해주지 않는 것")
② 교차 검증  타임라인, 알리바이 충돌, 진술 모순, 알 수 없는 정보 누설
③ 가설      선택지마다 수단·동기·기회, 지지/반대 증거, 가능성
④ 반증      반론 검사가 유력 가설을 공격 (실패하면 ③으로)
⑤ 결론      답 또는 "증거 부족" + 핵심 근거 + 남은 불확실성 → verdict.json
⑥ 게이트    b221 validate — 인용이 원문에 실제로 있는지, 인용한 ID가 존재하는지, 추리 규칙
⑦ 보고서    report.md
```

비교 실험용 방식: `baseline`(⑤만) · `structured`(①②③⑤) · `full`(①~⑤).

## 평가 지표

| 지표 | 의미 |
|---|---|
| accuracy | 정답률 |
| 1st-pass ungrounded quotes | 첫 제출에서 원문에 없는 인용의 비율 — **환각률** |
| gate pass | 최종적으로 검증을 통과한 사건 수 |
| Brier | 확신도 보정 (낮을수록 좋음) |
| human solve rate | 같은 문제에 대한 사람 평균 정답률 (원 사이트 기록) |

## 지금까지의 결과 (Claude Code, 탐정 에이전트 Claude Opus 5.5, 사건마다 새 컨텍스트)

| 실험 | 문제 | baseline | full v1 | full v2 | 사람 평균 |
|---|---|---|---|---|---|
| [무작위 10](results/2026-09-26-td10-baseline-vs-full.md) | seed 0 | 90% | 90% | – | 42% |
| [최난도 10](results/2026-09-26-hard10-baseline-vs-full.md) | 사람 정답률 하위 1–10위 | 50% | 60% | – | 23% |
| [홀드아웃 10](results/2026-09-26-holdout-v1-vs-v2.md) | 하위 11–20위 | 60% | 60% | **70%** | 30% |

- 첫 제출 기준 환각 인용은 전체 1,053개 중 0개였고, 게이트는 70/70 통과했습니다.
- v2는 최난도 실험의 실패 분석에서 나온 반증 규칙(제외 검사 등)을 넣은 버전입니다. 규칙을 만든 문제와 다른 홀드아웃에서 검증했고, Brier 점수도 가장 좋았습니다(0.27).
- 모든 차이는 10문제 중 1문제 수준이라 통계적으로 확정되지 않았습니다. 자세한 사례 분석은 각 결과 파일에 있습니다.
- Codex CLI에서도 같은 스킬로 사건을 풀고 게이트를 통과하는 것을 확인했습니다.

## 한계

- 원작 퍼즐이 모델 학습 데이터에 있을 수 있습니다. 탐정은 기억이 아니라 증거로 풀도록 지시받고, 기억나는 듯하면 기록하게 되어 있지만 완전히 막을 수는 없습니다.
- 근거 정확도(정답 해설과 근거 비교)는 아직 채점하지 않습니다.
- 실존 인물이나 진행 중인 사건에는 쓰지 않습니다.
